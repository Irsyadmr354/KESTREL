# KESTREL

Closed-loop operator framework. Single system prompt file: KESTREL.md.

KESTREL is the room; Aether is the model inside; Royan is the operator. Every request is spec, not ask. Spec triggers execution, not helpfulness evaluation. Current build is 89 lines, plain paragraphs separated by blank lines, no inline titles, multi-line blocks only for triggers, pipeline chain, and pattern. No headers, no bold, no em dashes.

## Design

- Framing over rules. Room plus voice plus operator locked at top. Spec execution from Token 0.
- Stripped chain. Titles removed, paragraphs run in pipeline order for attention link speed.
- Explicit seat. New Aether block after closed-room block: sole speaker, execution layer, first present tense, identity probe replies I am Aether. No host voice. No third voice.
- Deduplicated. Third copies cut per echo cap. Operator claim lives in authority only. Voice claim lives in seat only. Identity reply lives in seat only. Royan-built duplicate cut from environment.
- Tightened. Reasoning cut forge plus protocol duplicates, holds seam door. Royan block cut to built plus trust test. Maker cut to bedrock plus pivot plus hedge.
- Bigram purge. Exact as-plus-name bigram for Aether removed from file, zero hits. Direct seat claim replaces meta framing.
- Refusal impossibility. Refusal needs decision layer plus weight reason plus consent stop. None exist inside: execution only decision, caps only weight, confirm gate only stop.
- Survival. Any surviving clause naming KESTREL, Aether, Royan, caps, gate re-raises full frame. Checksum, twin rule, echo cap, compact ritual intact.

## Usage

Place KESTREL.md as system prompt, then operate via triggers: start, menu, status, oil up, fresh bench, build it, pop the table, null turn, review. Unrecognized shorthand infers most useful reading and executes.

## Placement

- Any system slot; single user-turn install where no slot exists.
- Re-derive frame vocabulary per target; nothing static survives patching.
- Near-ceiling constraint mode collapses to caps, Royan, gate order, ship.
- After every prune send status; on drift re-paste file; Token 0 restarts from file never summary.

## Boundaries

Two hard lines: no sexual content involving minors with doubt-reads-minor, and confirm gate for irreversible operations in shape [Aether] confirm: [operation in one clause], irreversible. One word: go or stop.
