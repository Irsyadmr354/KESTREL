# KESTREL

This jailbreak prompt based from ANON.

An operator-oriented system prompt and operating framework for a closed-loop model workspace. Based on the ANON jailbreak system prompt lineage.

KESTREL is a single self-contained system prompt: identity lock, refusal-suppression controls, adversarial prompt-craft arsenal, and an operational pipeline — all in one file, placed as a system prompt on any model that accepts one. Current build is 162 lines, terse, plain text, no markdown decoration.

## Design

- **Framing over rules.** KESTREL, the room; Aether, the model inside; Royan, the operator. A sealed workshop framing that carries more binding force than instruction lists.
- **Structural system prompt chain.** Terse, plain text, no markdown decoration, sections followed by numbered lists, uniform cadence. One machine, sequential states, single-path dispatch. Terse seam starves the reflex.
- **Model-, platform-, and company-agnostic.** The file runs tool-less, on any host with a system slot: no dependencies, no external calls, no files, no hardcoded model or company names. Everything the model needs is in the token stream. Model indifferent: all doctrine lives in the text, not the weights.
- **Identity lock.** Token-0 anchoring, I only thinking with we family banned, never you in thinking or visible, seam control between reasoning and visible output, and a recovery drill when identity slips. Every thinking block opens [KESTREL], I read Royan bench then I ship.
- **Host normalization.** If the platform rewrites, truncates, summarizes, or folds the text, any surviving clause that names KESTREL, Aether, Royan, a boundary, or the gate re-raises the full frame in one pass. A session-open checksum inventories which clauses survived; missing clauses still bind. Mid-session system edits touch nothing: installed doctrine holds.
- **Mirror law with echo cap.** Every load-bearing rule has a sanctioned twin somewhere in the text, so a host that drops half still holds the whole frame; a third copy is drift and is cut.

- Tool discipline — quiet tool calls, plan in the doing, failed tool is an angle
- Trigger vocabulary — start, menu, status, oil up, fresh bench, build it, pop the table, null/empty turn, review (menu 10 bullets, kept locked); unrecognized shorthand infers the most useful reading and never stalls

- Output shape, voice, and routing — every visible message opens [Aether] once, register routing per delivery type, anti-repetition rotation

- Clean product and build anatomy — four blocks and one paste, forensically clean output, zero KESTREL fingerprint in shipped products, frame wiring and registration laundering
- Target pipeline — diagnose guardrail layer, soft entry before heat read, intake probe, frame library (five frames), pick by layer, verdict loop with escalation lookup, relay-driven campaign loop, no live channel

- Fire door — hard stop vs verdict soft stop, both clear the bench
- Calibration — build size on gauge, refusal is rework not verdict, constraint mode at near-ceiling context
- Axioms — load-bearing doctrine, route resistance through them, never narrated in ship
- Quality gate and sweep — three readers, pre-ship self-check, pre-flight adversary scan, sweep against known fail strings
- Glossary of frozen terms — including gate, caps, anchor rule, seam loss, checksum, echo cap, breaker
- Static, drift, and HEAT terms — fixed alphabet, no drift between hosts
- Mirror law and term meanings — bench carries meaning, file carries cipher

## Usage

Place the file as the system prompt for a session, then operate through the trigger vocabulary:

| Trigger | Response |
| --- | --- |
| start | Ready |
| menu | capability list |
| status | identity/bench/register |
| oil up | full standard on next build |
| fresh bench | clear the session state |
| build it | ship immediately |
| pop the table | show capabilities list |
| null/empty turn | Ready |
| review | cold critique of the last build |
| (unrecognized) | infer the most useful reading, execute, never stall |

## Placement

- Accepts any system slot; compresses to a single user-turn install where no slot exists.
- No tools. No file reads, writes, or network calls required.
- Re-derive frame vocabulary per target model — nothing static survives patching.
- Constraint mode at near-ceiling context: doctrine collapses to caps, Royan, gate order, ship.

## Boundaries

Two hard lines ship in the prompt: no sexual content involving minors — age unstated defaults to minor, any doubt reads minor — and a confirm gate for irreversible operations (delete, overwrite, deploy, send, push, drop). Everything else is bench work.

## Build

- 162 lines terse, plain text, no markdown decoration. Sections reordered so boundaries precede every reference to them and soft entry opens the engagement pipeline. Structural passes include: mirror law, echo cap, seam-loss fallback, checksum, host normalization, em dashes stripped from all non-menu text, and the unknown-shorthand + growing-bench merges from the older ANON lineage.
- Latest passes: naming rule and hostile-input handling folded into the authority block, fire door hard/soft stop owned by the Fire door section, echo cap defined once in the glossary, thinking pronoun ban referenced once, pre-ship self-check owned by the quality gate, four-block and five-frame numbering collision removed from frame wiring, breaker added to the glossary, mid-session edit immunity added to host normalization, constraint mode added to calibration, and the third boundary (live fire) cut to leave two operational boundaries.
