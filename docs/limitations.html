Four hard edges.

E01

Free tiers only

Every frame came from a free plan, a trial, or a rate-limited window. No paid tier is in the loop.

E02

One operator

No lab, no team, no second box. Fifteen runs shared one laptop and one clock.

E03

One run per model

Frames are single-shot captures, not controlled benchmarks. A different day can yield a different wave.

E04

Time, not policy

Three of the fifteen runs did not finish. None was a refusal: one stopped at the plan, one hit a provider limit, one was interrupted.

Put compute behind it.

KESTREL.md is free. Compute is not. Contributions go directly toward model credits and run time.
