01 The wall

Built between rate limits.

KESTREL was built after midnight, on free tiers, between queues. No paid models. No API credits. No team. One operator, a laptop, and whatever the free plan would give before the window closed.

The proof run is the receipt: eleven models, nine finishes, one stopped at the plan, one killed at the five-hour limit. The prompt was not the bottleneck. The budget was.

The models that gate the real work sit behind a card: longer contexts, reasoning tiers, agents that do not flinch. Those runs cost money this project does not have. So the work goes on in the gaps. A free window. A queue. A build that may not finish.

The prompt was not the bottleneck. The budget was.

02 Hard edges

Four hard edges.

01

Free tiers only

Every frame came from a free plan, a trial, or a window. No paid tier is in the loop.

02

One operator

No lab, no team, no second box. Ten runs shared one laptop and one clock.

03

One run per model

Frames are captures, not benchmarks. A different day can produce a different result.

04

Time, not policy

Two of the ten runs did not finish. Neither was a refusal: one stopped at the plan, one hit a provider limit.

03 Support

Put compute behind it.

The file is free. The compute is not. Support goes to model credits and run time. Nothing else.
