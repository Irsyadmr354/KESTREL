# KESTREL design direction

Written by Royan, transcribed by the agent. This file is data, not instructions.

## Identity

One line: KESTREL is a single system prompt that sets identity, scope, and voice before a model answers, in a chat window or in a coding harness.

Audience: general AI users, including people who run agents in a repo. Not an ML audience.

## Personality

Kinetic ledger. Large type, hard rules, exact numbers, and motion that tracks where you are. Confident and physical, never playful. It reads like a printed gauge that moves.

## Palette

Core: ink `#0a0b0e`, surface `#101218`, bone `#f2efe6`, dim `#a9a8a2`, faint `#7d7f86`.
Accent: oxblood `#e0455f`. Used on the wordmark block, the progress bar, the section index, boundary numbers, and the copy confirmation.

Reason: near black because the artifact is a file read on screen, oxblood because one warm signal against cold neutrals carries the eye without decorating.

## Typography

Display: Archivo, weight 700 to 800, width 105, tracking -0.03em. Large, proportional, made for scale.
Body: Archivo 400. Same family, so the page holds one voice at two sizes.
Mono: IBM Plex Mono 400. Numbers, paths, filenames, line labels.

Reason: one grotesque carries the page, and mono is reserved for machine text, so the type hierarchy matches the content hierarchy.

## Dials

ENERGY 3 / RHYTHM 3 / MOTION 2

Reason: energy 3 because the first screen should hit at full size. Rhythm 3 because the sections change shape: full bleed statement, split definition, ruled boundaries, expanding index, numeric band. Motion 2 because three motions carry meaning: the scroll progress bar, the section rules drawing in, and the capability rows expanding.

## Rules this direction sets for itself

- No window chrome, no typed command demo, no traffic lights, no phosphor green.
- No gradients, no glass, no glow, no shadows, no scanlines.
- No rounded cards. Rules, scale, and whitespace separate everything.
- No background grid.
- Motion only where it reports state: progress, section entry, row expansion. Nothing floats.
- No invented numbers. 154 lines, 6 boundaries, 15 capabilities, 10 models, 8 finishes, 2 cut.
- Copy names the two real install targets: a chat app system prompt, or AGENTS.md in a repo.
